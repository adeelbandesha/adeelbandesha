## About

I'm a senior software engineer at Genius Mind Zone in Faisalabad. Most of my work is building backends in Node.js and TypeScript, along with the React Native apps that run on top of them. I also use Python for AI work, mainly image generation and upscaling, and I look after deployments with Docker and GitHub Actions.

On a normal day that means writing APIs, designing databases, getting mobile releases out and keeping the CI pipelines green. I try to write code the next developer can pick up without a long handover.

I speak English, Urdu and Arabic, and I'm comfortable working remotely with teams in other time zones.

### Quran Learning App &nbsp; <img src="https://img.shields.io/badge/status-in%20development-7F00FF?style=flat-square" alt="In development" /> <img src="https://img.shields.io/badge/repo-private-302b63?style=flat-square&logo=github" alt="Private repo" />

A mobile app for reading the Quran and memorizing it. Instead of plain text, it shows the actual Mushaf pages using the original glyph fonts, so each page looks the same as the printed copy. Readers can choose the layout they learned on: KFGQPC V4, KFGQPC V2, or the IndoPak 15 and 16 line editions.

- Mushaf pages rendered from glyph fonts, with four layouts to choose from
- Built for memorization as well as everyday reading
- Translations, tafsir, word by word meanings and recitation audio
- All Quranic text and data taken from verified sources
