### Quran Learning App &nbsp; <img src="https://img.shields.io/badge/status-in%20development-5B21B6?style=flat-square" alt="In development" /> <img src="https://img.shields.io/badge/repo-private-1E293B?style=flat-square&logo=github" alt="Private repo" />

A mobile app for reading the Quran and memorizing it. Instead of plain text, it shows the actual Mushaf pages using the original glyph fonts, so each page looks the same as the printed copy. I'm building both sides of it: the React Native app and the Node.js API that serves its content.

- Mushaf pages rendered from glyph fonts, with four layouts: KFGQPC V4, KFGQPC V2, and IndoPak 15 and 16 line
- Built for memorization as well as everyday reading
- Translations, tafsir, word by word meanings and recitation audio
- All Quranic text and data taken from verified sources
